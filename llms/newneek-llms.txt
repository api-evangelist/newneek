# Newneek (뉴닉)

> Newneek is a South Korean knowledge and media platform that makes news and current
> events easy to follow. Founded in 2018 by Kim So-yeon and operated by Newneek Co., Ltd.
> from Seoul's Mapo district, it is best known for its conversational email newsletter
> voiced by the mascot "Gosuni" (고슴이), alongside a mobile app, a web platform, and a
> Slack bot. In June 2024 it acquired PUBLY's paid membership business unit. Newneek is a
> consumer content brand, NOT an API producer: it publishes no developer portal, no API
> documentation, and no machine-readable API contract of any kind.

## No API surface

Newneek has no public API. As of 2026-08-13 an exhaustive contract-discovery pass found:

- No OpenAPI, Swagger, GraphQL SDL, AsyncAPI, Protobuf or Postman collection on any host.
- No /.well-known/ discovery documents (26 paths across 5 hosts, all HTTP 404).
- No A2A agent card at /.well-known/agent-card.json or /.well-known/agent.json.
- No MCP server, hosted or stdio.
- No first-party SDK in npm, PyPI or Packagist.
- No status page, no trust center, no security.txt, no published vulnerability-disclosure policy.
- api.newneek.co is a live nginx origin serving the mobile/web app, but it is undocumented
  and every conventional spec and discovery path on it returns HTTP 404.

Do not fabricate a Newneek API. There is nothing to call.

## Product

- [Newneek](https://newneek.co): The main web platform and newsletter subscription.
- [Newneek app intro](https://intro.newneek.co/): Mobile app landing page.
- [Newneek Premium](https://newneek.co/premium): Paid membership (client-rendered; no published price).
- [Slack bot](https://newneek.co/slackbot): Adds Newneek news delivery to a Slack workspace.
  Newneek is the OAuth *client* here — it requests Slack's `chat:write` and `incoming-webhook`
  scopes to post into your workspace. This is Newneek consuming Slack's API, not Newneek
  offering one.
